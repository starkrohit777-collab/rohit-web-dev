1️⃣ Gale-Shapley Algorithm (Stable Matching)

The Gale-Shapley algorithm solves the stable marriage problem where we have equal numbers of men and women, each with their own preference lists. The algorithm produces a stable matching where no unmatched pair would prefer each other over their current partners.

⏱️ Time & Space Complexity

Complexity TypeValue
Time Complexity (All Cases)O(n²)
Space ComplexityO(n²)

🐍 Python Implementation

def gale_shapley(men_prefs, women_prefs):
    """
    Gale-Shapley algorithm for stable matching
    Time Complexity: O(n²)
    Space Complexity: O(n²)
    """
    n = len(men_prefs)
    free_men = list(range(n))
    proposal_index = [0] * n
    engaged = [-1] * n
    women_rank = [{man: idx for idx, man in enumerate(women_prefs[i])} 
                  for i in range(n)]
    
    while free_men:
        man = free_men[0]
        woman = men_prefs[man][proposal_index[man]]
        proposal_index[man] += 1
        
        if engaged[woman] == -1:
            engaged[woman] = man
            free_men.pop(0)
        else:
            current_man = engaged[woman]
            if women_rank[woman][man] < women_rank[woman][current_man]:
                engaged[woman] = man
                free_men.pop(0)
                free_men.append(current_man)
    
    return engaged

# Test
men_prefs = [[0,1,2], [1,0,2], [0,1,2]]
women_prefs = [[1,0,2], [0,1,2], [0,1,2]]
result = gale_shapley(men_prefs, women_prefs)
print("Stable matching:", result)

☕ Java Implementation

import java.util.*;

public class GaleShapley {
    public static int[] galeShapley(int[][] menPrefs, int[][] womenPrefs) {
        int n = menPrefs.length;
        Queue<Integer> freeMen = new LinkedList<>();
        for (int i = 0; i < n; i++) freeMen.add(i);
        
        int[] proposalIndex = new int[n];
        int[] engaged = new int[n];
        Arrays.fill(engaged, -1);
        
        int[][] womenRank = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                womenRank[i][womenPrefs[i][j]] = j;
            }
        }
        
        while (!freeMen.isEmpty()) {
            int man = freeMen.poll();
            int woman = menPrefs[man][proposalIndex[man]++];
            
            if (engaged[woman] == -1) {
                engaged[woman] = man;
            } else {
                int currentMan = engaged[woman];
                if (womenRank[woman][man] < womenRank[woman][currentMan]) {
                    engaged[woman] = man;
                    freeMen.add(currentMan);
                } else {
                    freeMen.add(man);
                }
            }
        }
        return engaged;
    }
}

📌 Key Points for Exam

  • Always produces a stable matching
  • Man-optimal: Each man gets the best possible partner among all stable matchings
  • Woman-pessimal: Each woman gets the worst possible partner among all stable matchings
  • Running time is O(n²) regardless of input
  • Can be extended to hospital-resident matching problem

2️⃣ Selection Sort

Selection sort is an in-place comparison sorting algorithm that divides the input list into sorted and unsorted regions. It repeatedly selects the smallest element from the unsorted region and swaps it with the first element of the unsorted region.

⏱️ Time & Space Complexity

Complexity TypeValue
Best Case TimeO(n²)
Average Case TimeO(n²)
Worst Case TimeO(n²)
Space ComplexityO(1)

🐍 Python Implementation

def selection_sort(arr):
    """
    Selection Sort Algorithm
    Time Complexity: O(n²) for all cases
    Space Complexity: O(1)
    """
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# Test
arr = [64, 25, 12, 22, 11]
print("Sorted array:", selection_sort(arr.copy()))

📌 Key Points for Exam

  • In-place algorithm: No extra space required
  • Unstable sort: Does not preserve relative order of equal elements
  • Performs minimum number of swaps: O(n) swaps
  • Good for small datasets or when memory is limited
  • Always O(n²) regardless of input order

3️⃣ BFS in Directed Graph

Breadth-First Search (BFS) is a graph traversal algorithm that explores vertices in order of their distance from the source node. It uses a queue data structure and is particularly useful for finding shortest paths in unweighted graphs.

⏱️ Time & Space Complexity

Complexity TypeValue
Time ComplexityO(V + E)
Space ComplexityO(V)

🐍 Python Implementation

from collections import deque

def bfs_reachable(graph, start):
    """
    BFS to find all reachable nodes
    Time Complexity: O(V + E)
    Space Complexity: O(V)
    """
    visited = set()
    queue = deque([start])
    visited.add(start)
    reachable_nodes = []
    
    while queue:
        vertex = queue.popleft()
        reachable_nodes.append(vertex)
        
        for neighbor in graph.get(vertex, []):
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    
    return reachable_nodes

# Test
graph = {
    0: [1, 2],
    1: [2],
    2: [3],
    3: [],
    4: [0]
}
print("Nodes reachable from 0:", bfs_reachable(graph, 0))

📌 Key Points for Exam

  • Uses queue data structure (FIFO)
  • Finds shortest path in unweighted graphs
  • Can detect if graph is bipartite
  • Used in web crawling, social networks, GPS navigation
  • Memory requirement is O(V) for storing visited nodes

4️⃣ Topological Ordering

Topological ordering of a Directed Acyclic Graph (DAG) is a linear ordering of vertices such that for every directed edge (u,v), vertex u comes before v in the ordering. Kahn's algorithm uses indegree counts to achieve this ordering.

⏱️ Time & Space Complexity

Complexity TypeValue
Time ComplexityO(V + E)
Space ComplexityO(V)

🐍 Python Implementation

from collections import deque

def topological_sort_kahn(graph, vertices):
    """
    Kahn's Algorithm for Topological Sort
    Time Complexity: O(V + E)
    Space Complexity: O(V)
    """
    indegree = {v: 0 for v in vertices}
    for v in vertices:
        for neighbor in graph.get(v, []):
            indegree[neighbor] += 1
    
    queue = deque([v for v in vertices if indegree[v] == 0])
    result = []
    
    while queue:
        vertex = queue.popleft()
        result.append(vertex)
        
        for neighbor in graph.get(vertex, []):
            indegree[neighbor] -= 1
            if indegree[neighbor] == 0:
                queue.append(neighbor)
    
    if len(result) != len(vertices):
        return None  # Cycle detected
    return result

# Test
graph = {0: [1, 2], 1: [3], 2: [3], 3: [4], 4: []}
vertices = [0, 1, 2, 3, 4]
print("Topological order:", topological_sort_kahn(graph, vertices))

📌 Key Points for Exam

  • Only possible for Directed Acyclic Graphs (DAGs)
  • Multiple valid topological orders may exist
  • Can detect cycles in directed graphs
  • Used in scheduling, dependency resolution, course prerequisites
  • Kahn's algorithm uses indegree concept

5️⃣ Kruskal's Algorithm (Minimum Spanning Tree)

Kruskal's algorithm finds the Minimum Spanning Tree (MST) of a connected undirected graph by repeatedly adding the smallest edge that doesn't create a cycle. It uses Union-Find data structure for cycle detection.

⏱️ Time & Space Complexity

Complexity TypeValue
Time ComplexityO(E log E) or O(E log V)
Space ComplexityO(V + E)

🐍 Python Implementation

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        if self.rank[px] < self.rank[py]:
            self.parent[px] = py
        elif self.rank[px] > self.rank[py]:
            self.parent[py] = px
        else:
            self.parent[py] = px
            self.rank[px] += 1
        return True

def kruskal(vertices, edges):
    edges.sort(key=lambda x: x[2])
    uf = UnionFind(vertices)
    mst = []
    total_cost = 0
    
    for u, v, weight in edges:
        if uf.union(u, v):
            mst.append((u, v, weight))
            total_cost += weight
    
    return mst, total_cost

# Test
edges = [(0, 1, 10), (0, 2, 6), (0, 3, 5), (1, 3, 15), (2, 3, 4)]
mst, cost = kruskal(4, edges)
print("MST edges:", mst)
print("Total cost:", cost)

📌 Key Points for Exam

  • Greedy algorithm - always picks smallest edge
  • Uses Union-Find for cycle detection
  • Works for disconnected graphs (produces forest)
  • Time dominated by sorting edges
  • Prim's algorithm is alternative for dense graphs

6️⃣ Huffman Coding

Huffman coding is a lossless data compression algorithm that assigns variable-length codes to characters based on their frequencies. More frequent characters get shorter codes, achieving optimal prefix-free encoding.

⏱️ Time & Space Complexity

Complexity TypeValue
Time ComplexityO(n log n)
Space ComplexityO(n)

🐍 Python Implementation

import heapq
from collections import Counter

class HuffmanNode:
    def __init__(self, char, freq):
        self.char = char
        self.freq = freq
        self.left = None
        self.right = None
    
    def __lt__(self, other):
        return self.freq < other.freq

def build_huffman_tree(text):
    freq = Counter(text)
    heap = [HuffmanNode(char, freq) for char, freq in freq.items()]
    heapq.heapify(heap)
    
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        merged = HuffmanNode(None, left.freq + right.freq)
        merged.left = left
        merged.right = right
        heapq.heappush(heap, merged)
    
    return heap[0] if heap else None

def generate_codes(node, code="", codes=None):
    if codes is None:
        codes = {}
    if node is None:
        return codes
    if node.char is not None:
        codes[node.char] = code
    generate_codes(node.left, code + "0", codes)
    generate_codes(node.right, code + "1", codes)
    return codes

# Test
text = "huffman coding"
encoded, codes, root = huffman_encoding(text)
print("Huffman Codes:", codes)
print("Encoded:", encoded)

📌 Key Points for Exam

  • Optimal prefix-free encoding
  • Greedy algorithm - always picks smallest frequencies
  • Used in ZIP, JPEG, MP3 compression
  • No codeword is prefix of another
  • Tree is full binary tree (all internal nodes have 2 children)

7️⃣ Parallel Merge Sort

Parallel merge sort divides the array into smaller subarrays that are sorted concurrently using multiple processors or threads. The divide-and-conquer nature of merge sort makes it naturally parallelizable.

⏱️ Time & Space Complexity

Complexity TypeValue
Sequential TimeO(n log n)
Parallel TimeO((n log n)/p)
Space ComplexityO(n)

🐍 Python Implementation

import multiprocessing as mp
import time
import random

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

def parallel_merge_sort(arr, depth=0, max_depth=3):
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    
    if depth < max_depth and mp.cpu_count() > 1:
        with mp.Pool(2) as pool:
            left_result = pool.apply_async(parallel_merge_sort, 
                                          (arr[:mid], depth+1, max_depth))
            right_result = pool.apply_async(parallel_merge_sort, 
                                           (arr[mid:], depth+1, max_depth))
            left, right = left_result.get(), right_result.get()
    else:
        left = parallel_merge_sort(arr[:mid], depth+1, max_depth)
        right = parallel_merge_sort(arr[mid:], depth+1, max_depth)
    
    return merge(left, right)

# Performance test
arr = [random.randint(1, 10000) for _ in range(10000)]
start = time.time()
sorted_arr = parallel_merge_sort(arr)
print(f"Time taken: {time.time() - start:.4f} seconds")

📌 Key Points for Exam

  • Divide-and-conquer algorithm
  • Fork/Join framework in Java, multiprocessing in Python
  • Speedup depends on number of processors
  • Amdahl's law: speedup limited by sequential portion
  • Load balancing important for efficiency

8️⃣ Interval Scheduling

Interval scheduling problem: Given a set of intervals with start and finish times, select the maximum number of non-overlapping intervals. The greedy algorithm that selects intervals with earliest finish time is optimal.

⏱️ Time & Space Complexity

Complexity TypeValue
Unweighted TimeO(n log n)
Weighted TimeO(n log n)
Space ComplexityO(n)

🐍 Python Implementation

def interval_scheduling(intervals):
    """
    Greedy algorithm for interval scheduling
    Time Complexity: O(n log n) for sorting
    Space Complexity: O(n)
    """
    intervals.sort(key=lambda x: x[1])
    
    selected = []
    last_finish = float('-inf')
    
    for start, finish in intervals:
        if start >= last_finish:
            selected.append((start, finish))
            last_finish = finish
    
    return selected

def weighted_interval_scheduling(intervals):
    """
    Dynamic programming for weighted interval scheduling
    """
    intervals.sort(key=lambda x: x[1])
    n = len(intervals)
    start = [i[0] for i in intervals]
    finish = [i[1] for i in intervals]
    weight = [i[2] for i in intervals]
    
    def find_last_non_conflict(index):
        low, high = 0, index - 1
        while low <= high:
            mid = (low + high) // 2
            if finish[mid] <= start[index]:
                if finish[mid + 1] <= start[index]:
                    low = mid + 1
                else:
                    return mid
            else:
                high = mid - 1
        return -1
    
    dp = [0] * n
    dp[0] = weight[0]
    
    for i in range(1, n):
        include = weight[i]
        last = find_last_non_conflict(i)
        if last != -1:
            include += dp[last]
        dp[i] = max(include, dp[i-1])
    
    return dp[n-1]

# Test
intervals = [(1, 3), (2, 5), (3, 9), (6, 8)]
print("Maximum intervals:", len(interval_scheduling(intervals)))

📌 Key Points for Exam

  • Greedy algorithm optimal for unweighted case
  • Earliest finish time gives optimal solution
  • Weighted version requires dynamic programming
  • Applications: task scheduling, resource allocation
  • Can be extended to interval partitioning

9️⃣ Dijkstra's Algorithm

Dijkstra's algorithm finds the shortest paths from a source vertex to all other vertices in a weighted graph with non-negative edge weights. It uses a greedy approach with a priority queue.

⏱️ Time & Space Complexity

Complexity TypeValue
Time ComplexityO((V + E) log V)
Space ComplexityO(V)

🐍 Python Implementation

import heapq

def dijkstra(graph, start):
    """
    Dijkstra's shortest path algorithm
    Time Complexity: O((V + E) log V) with binary heap
    Space Complexity: O(V)
    """
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    pq = [(0, start)]
    visited = set()
    previous = {node: None for node in graph}
    
    while pq:
        current_dist, current = heapq.heappop(pq)
        
        if current in visited:
            continue
        visited.add(current)
        
        if current_dist > distances[current]:
            continue
        
        for neighbor, weight in graph[current].items():
            distance = current_dist + weight
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                previous[neighbor] = current
                heapq.heappush(pq, (distance, neighbor))
    
    return distances, previous

# Test
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1}
}
distances, previous = dijkstra(graph, 'A')
print("Shortest distances from A:", distances)

📌 Key Points for Exam

  • Works only with non-negative edge weights
  • Greedy algorithm: always picks closest unvisited vertex
  • Can be implemented with binary heap for efficiency
  • Does not work with negative weights (use Bellman-Ford)
  • Applications: GPS navigation, network routing

🔟 0/1 Knapsack using Dynamic Programming

The 0/1 knapsack problem: Given items with weights and values, and a knapsack with capacity W, select items to maximize total value where each item can be taken at most once. DP solution uses optimal substructure property.

⏱️ Time & Space Complexity

Complexity TypeValue
Time ComplexityO(n × W)
Space Complexity (2D)O(n × W)
Space Complexity (1D)O(W)

🐍 Python Implementation

def knapsack_01(weights, values, capacity):
    """
    0/1 Knapsack using Dynamic Programming (2D)
    Time Complexity: O(n * capacity)
    Space Complexity: O(n * capacity)
    """
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i-1] <= w:
                dp[i][w] = max(values[i-1] + dp[i-1][w - weights[i-1]], 
                              dp[i-1][w])
            else:
                dp[i][w] = dp[i-1][w]
    
    return dp[n][capacity]

def knapsack_01_optimized(weights, values, capacity):
    """
    Space-optimized version
    Time Complexity: O(n * capacity)
    Space Complexity: O(capacity)
    """
    n = len(weights)
    dp = [0] * (capacity + 1)
    
    for i in range(n):
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], values[i] + dp[w - weights[i]])
    
    return dp[capacity]

# Test
weights = [2, 3, 4, 5]
values = [3, 4, 5, 6]
capacity = 5
print(f"Maximum value: {knapsack_01(weights, values, capacity)}")
print(f"Maximum value (optimized): {knapsack_01_optimized(weights, values, capacity)}")

📌 Key Points for Exam

  • Classic dynamic programming problem
  • Optimal substructure: solution depends on subproblems
  • Overlapping subproblems: DP table stores results
  • Space optimization: iterate capacity backwards
  • Not polynomial-time (pseudo-polynomial)
  • Greedy fails for 0/1 knapsack

🎯 Algorithm Selection Guide

  • Stable Matching: Use Gale-Shapley for pairing problems
  • Small Arrays: Selection sort for memory-constrained environments
  • Graph Traversal: BFS for unweighted shortest paths
  • Dependency Resolution: Topological sort for DAGs
  • Network Design: Kruskal's for MST in sparse graphs
  • Data Compression: Huffman coding for lossless compression
  • Large Datasets: Parallel merge sort for multi-core systems
  • Scheduling: Interval scheduling for task selection
  • Shortest Path: Dijkstra for non-negative weights
  • Resource Allocation: DP knapsack for optimization

🔑 Important Formulas

  • Union-Find: α(n) - inverse Ackermann function (nearly constant)
  • Amdahl's Law: S = 1 / ((1-P) + P/N) where P is parallel portion, N is processors
  • Master Theorem: T(n) = aT(n/b) + f(n)
  • BFS Distance: d(v) = d(u) + 1 for edge (u,v)
  • Dijkstra Invariant: dist[u] ≤ dist[v] for processed vertices
  • Knapsack Recurrence: dp[i][w] = max(dp[i-1][w], val[i] + dp[i-1][w-wt[i]])
